Java 9 (September 2017)===

Module System: ====

Introduced Project Jigsaw to modularize the JDK code.

		A modular project requires a specific folder layout. Each module directory must contain a module-info.java file at its root. 

		tax-system/
├── com.service.provider/
│   ├── module-info.java
│   └── com/service/provider/
│       ├── api/
│       │   └── TaxCalculator.java      <-- Public API (Exported)
│       └── internal/
│           └── Obfuscator.java         <-- Hidden Engine (Not Exported)
│
└── com.client.consumer/
    ├── module-info.java
    └── com/client/consumer/
        └── App.java


// File: tax-system/com.service.provider/module-info.java
module com.service.provider {
    // Only expose the API package
    exports com.service.provider.api; 
}





        Module 1: The Core Engine (com.engine.core)This module contains the logic. We will explicitly export the package containing PaymentService while keeping InternalHelper entirely hidden from other modules.1. The Module Descriptorjava// File: com.engine.core/module-info.java
module com.engine.core {
    // Only export this specific package to the outside world
    exports com.engine.core; 
}
Use code with caution.2. The Shared Classjava// File: com.engine.core/com/engine/core/PaymentService.java
package com.engine.core;

public class PaymentService {
    public void process(double amount) {
        System.out.println("Processing payment of ₹" + amount);
    }
}
Use code with caution.3. The Hidden Internal Classjava// File: com.engine.core/com/engine/core/InternalHelper.java
package com.engine.core;

// Even though this class is public, it cannot be imported outside 
// this module because its package layout is strictly encapsulated.
public class InternalHelper {
    public void secureLog() {
        System.out.println("Internal secure logging...");
    }
}
Use code with caution.💻 Module 2: The Client Application (com.client.app)This module contains our application entry point. It must explicitly declare its dependency on the core engine module to use its classes.1. The Module Descriptorjava// File: com.client.app/module-info.java
module com.client.app {
    // Expressly declare dependency on the other module name
    requires com.engine.core; 
}
Use code with caution.2. The Main Application Codejava// File: com.client.app/com/client/app/MainApplication.java
package com.client.app;

// Import is permitted because com.engine.core exports this package
import com.engine.core.PaymentService; 

// Trying to import com.engine.core.InternalHelper here 
// will trigger a compile-time error!

public class MainApplication {
    public static void main(String[] args) {
        PaymentService service = new PaymentService();
        service.process(1500.50);
    }
}

Compile and Run via Terminal, use the --module-source-path flag during compilation and the --module flag for execution.

Step 1: Compile both modules into an output folder (mods)bash

javac -d mods --module-source-path . $(find . -name "*.java")


Step 2: Run the Main application using the module pathwaybash

java --module-path mods --module com.client.app/com.client.app.MainApplication
